# Cell Nuclei Segmentation

Interactive demo for cell nuclei segmentation using U-Net and Attention U-Net, trained on the 2018 Data Science Bowl dataset.

Upload a microscopy image to segment nuclei. Optionally upload a ground truth mask to see full TP/FP/FN evaluation panels.
